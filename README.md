# project_with_pathy
# 🚀 Enterprise Task Management App

A clean, minimalist, and interactive web application designed to help users organize their daily goals effortlessly, track their progress, and manage personal profiles with a sleek soft-blue aesthetic.

---

## ✨ Features
* **User Authentication & Personalization:** Simple login system that securely captures user details (Name & Major) and reflects them directly in the profile dashboard.
* **Interactive Task Management:** Add and delete tasks seamlessly with real-time active task counting.
* **Modern UI/UX:** Clean, cardless design utilizing a calming pastel blue theme (`#f0f7ff`) and smooth toast notifications.
* **Local Storage Integration:** Persists user session data directly in the browser.

---

## 🛠️ Tech Stack
* **HTML5** (Semantic structure)
* **CSS3** (Modern styling & custom animations)
* **JavaScript (ES6+)** (Dynamic interactivity and DOM manipulation)
* **Git & GitHub** (Version control and collaborative workflows)
